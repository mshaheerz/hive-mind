**Twitter Thread**

1/6 Introducing cloud-cost-overview-card-set! 🚀 A lightweight, copy-paste React library that shows your AWS, GCP, and Azure spend in minutes. No heavy dashboards or auth tokens required. Easy peasy! ✨ #cloudcosts #react #easypick

2/6 Why waste engineering hours searching for a simple "What did we spend this month?" number? 🤔 These cards call native Cost APIs, format the result, and look good in any React app. Copy → Paste → Ship in minutes! 🚀 #devops #cloudcomputing

3/6 Quick Start in 5 minutes! 🕒
1. Install: `npm i cloud-cost-overview-card-set`
2. Add your read-only credentials
3. Drop a card anywhere: `import { AwsCostCard } from 'cloud-cost-overview-card-set'`
4. Open your app → you’ll see today’s spend in plain English! 📊 #reactjs #cloudcosts

4/6 What's inside? 🤔
| Card          | Size (gzip) | API call              | Auto-refresh |
|---------------|------------|-----------------------|-------------|
| `AwsCostCard`   | 4 kB       | AWS Cost Explorer     | every 10 min |
| `GcpCostCard`   | 4 kB       | GCP Cloud Billing API | every 10 min |
| `AzureCostCard` | 4 kB       | Azure Consumption API | every 10 min | #cloudcosts #react

5/6 Examples time! 🎉
1. One card: `<GcpCostCard currency="EUR" className="shadow-xl" />`
2. All three in a grid: `<div className="grid grid-cols-3 gap-4">...</div>`
3. Dark mode: `<AwsCostCard className="dark" />` #react #cloudcosts
